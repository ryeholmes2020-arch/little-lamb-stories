# Little Lamb Stories

Family website for [Little Lamb Stories](https://www.youtube.com/@littlelambstories2026) — a digital storybook library for heartwarming Filipino family films.

This is a **new standalone repository**. It is not part of `iq-games` or `iq-games-bots`.

## Pages

- `index.html` — homepage with hero, featured story, and category shelves
- `categories/` — Stories, Superheroes, Comedy, Bedtime, Family
- `stories/` — SEO episode pages with YouTube embed, Watch / Subscribe CTAs, and a parent question
- `parents.html` — parent resources and episode guides

## Local preview

Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## GitHub Pages

In the repository settings, set Pages source to **Deploy from a branch**, branch `main`, folder `/ (root)`.

## Design

Warm cream, meadow green, sky blue, and coral. Storybook library layout — not a dashboard. Coral buttons are reserved for Watch on YouTube and Subscribe.
